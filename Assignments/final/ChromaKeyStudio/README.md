🎥 Chroma Key Studio – Real-Time Background Removal Web App

📌 Overview

Chroma Key Studio is a browser-based computer vision application that performs real-time background removal using color segmentation techniques.

The app allows users to interact with their webcam feed, isolate background colors, and replace them with virtual environments.

⸻

🚀 Live Demo

👉 https://flourishing-llama-782cc6.netlify.app/

⸻

💻 Technologies Used

* HTML
* CSS
* JavaScript
* OpenCV.js (via Antigravity)

⸻

🧠 Key Concepts Demonstrated

* Real-time video processing
* Color segmentation in HSV space
* Binary masking
* Contour detection
* Background replacement (chroma key)

⸻

⚙️ Features

* 🎥 Live webcam feed
* 🎨 Click-to-select background color
* 🖼️ Virtual background replacement
* 🎛️ Adjustable HSV sliders for fine-tuning
* 🧪 Mask preview for debugging

⸻

⚠️ Notes

Best performance is achieved with:

* Simple or uniform backgrounds
* Good lighting conditions
* Strong contrast between subject and background

⸻

📂 Project Structure

* index.html → Main interface
* main.js → Computer vision logic
* style.css → UI styling
* assets/ → Background images

⸻

🎯 Purpose

This project demonstrates how computer vision techniques can be implemented directly in the browser without requiring a backend server.
