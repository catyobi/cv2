# Module 6 – Shape Detection with Contours

This module builds a contour-based pipeline to detect and analyze shapes.

The notebook loads an image, applies thresholding, finds contours, and filters shapes based on area.

Large shapes (area > 10,000) are highlighted with:
- Contours
- Bounding boxes
- Centroids
- Area labels
